# 業種別 数字診断 — MVP

## 目的
無料の単機能計算サイトをそのまま複製せず、利用者が入力した数字を複数KPIへ変換し、
業種別の参考レンジと比較して「次に確認する数字」を返す軽量Webツール。

## MVP
- 業種切替: 飲食、小売/EC、製造、専門サービス、SaaS
- 入力: 売上、原価、純利益、人件費、固定費
- 出力: 粗利率、純利益率、人件費率、概算損益分岐売上
- 業種別参考レンジとの比較
- 0–100の簡易スコア
- 最大3件の平易な改善ヒント
- 出典と免責を画面内表示

## 次の候補
1. 月次3〜12か月の推移CSV
2. 業種を細分化（飲食: QSR/フルサービス等）
3. 一次ソース中心のベンチマークデータ更新
4. 価格変更・原価改善・人件費改善のwhat-if
5. 結果をURL共有せずローカルPDF/CSV出力

## 品質原則
- 数字を「正解」と断定しない
- 出典と更新日を持つ
- 税務/融資/投資の自動判断をしない
- ユーザー入力を外部送信しない構成を優先
